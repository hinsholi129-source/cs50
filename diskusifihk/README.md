# Diskusi Fiqih Kontemporer

Aplikasi mobile Flutter untuk diskusi tentang fiqih kontemporer.

## Memulai

Pastikan Anda telah menginstal Flutter. Lihat https://flutter.dev/docs/get-started/install

Untuk menjalankan aplikasi:

```bash
flutter pub get
flutter run
```

## Struktur Proyek

- `lib/` berisi kode sumber Dart aplikasi.
- `assets/` (jika ada) untuk gambar, font, dll.
- `test/` untuk pengujian.
